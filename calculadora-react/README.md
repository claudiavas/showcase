# Calculadora React

Una calculadora simple construida con React.

## Funcionalidades

- Operaciones básicas (+, -, *, /)
- Interfaz clara e intuitiva
- Responsive design

## Instalación

```bash
npm install
```

## Uso

Para iniciar la aplicación en modo desarrollo:

```bash
npm start
```

Para crear un build para producción:

```bash
npm build
```
